# Autotile Fill

In the Auto Tiling window, fill a 47- or 16-tile autotile set from a single selected tile.

A plugin for the **GameMaker LTS 2026 IDE** by Piotr.

## Install

### Option A: manual (no GMPM needed)

1. Download the latest release and unzip/clone this repo - the `build\` folder has `AutotileFill.dll` + `AutotileFill.gmplugin` next to the installer.
2. Run `build\manual-install.ps1` (PowerShell): `powershell -ExecutionPolicy Bypass -File build\manual-install.ps1`
3. Launch GameMaker LTS 2026.
